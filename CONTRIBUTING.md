# Contributing to Hacker House Live Board & "Horn OK Please"

Thank you for your interest in contributing! This project is an open-source, voice-native web application built for the **Wispr Flow** hackathon, demonstrating both real-time hacker house collaboration and browser audio physics.

---

## 🎙️ Contributing by Voice or Code

Whether you are contributing code via a traditional IDE or voice-prompting through Wispr Flow:

1. **Fork the Repository**
   Create your own fork at `https://github.com/Kanhaiya76618/whisper-game`.

2. **Clone and Install**
   ```bash
   git clone https://github.com/<your-username>/whisper-game.git
   cd whisper-game
   npm install
   ```

3. **Development Modes**
   - **Local Dev Server:**
     ```bash
     npm run dev
     ```
     Access [http://localhost:3000](http://localhost:3000).
   - **Docker Container:**
     ```bash
     docker compose up --build
     ```

4. **Design Integrity: Warm Editorial Minimalism**
   - Palette: Ivory cream (`#FAF8EC`), muted beige (`#EAE7D5`), near-black ink (`#1C1B17`).
   - Typography: *Instrument Serif* for headlines, *Inter* for body, *Geist Mono* for telemetry.
   - Restraint: Hairline `1px` borders, no saturated neon accents, no heavy drop shadows.

5. **Submitting Changes**
   - If developing via voice instructions, maintain timestamped prompts in [`PROMPTS.md`](./PROMPTS.md).
   - Open a clean pull request against `main`.
